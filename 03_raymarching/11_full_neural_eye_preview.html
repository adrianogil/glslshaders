What is neural, limits, and Shadertoy setup

The exported network directly returns the final RGB of every pixel. There is no analytic eye mask, ray intersection, lighting pass, pigment atlas, procedural detail, or cached animation in this preview. The learned function covers yaw 32–76°, fixed pitch −5°, pupil 0–1, and hue 0–1. It is a conditional image representation, not an unrestricted 3D field. Fine detail and moving boundaries can differ from the teacher.

Paste 11_full_neural_eye.frag into Shadertoy’s Image tab. Leave all channels empty. Drag horizontally for view and vertically for pupil; release to orbit. Set IRIS_HUE near the top for hue. This local preview also exposes hue as a slider that changes the network input. Nothing has been uploaded to Shadertoy.
